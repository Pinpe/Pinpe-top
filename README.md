# Pinpe的云端

这是我的个人博客 [pinpe.top](https://pinpe.top) 的源代码。

## 这个仓库能干嘛

- **参考学习**：如果你也想用 Astro + Fuwari 搭博客，可以看我是怎么配置和定制的
- **直接 Fork**：拿去改成你自己的博客完全没问题，记得换掉文章和配置
- **提建议**：看到什么可以改进的地方，欢迎提 Issue

## 怎么跑起来

```bash
pnpm install   # 装依赖
pnpm dev       # 启动开发服务器，浏览器打开 http://localhost:4321
pnpm build     # 构建生产版本
```

## 技术相关

基于 [Fuwari](https://github.com/saicaca/fuwari) 主题构建，原主题的说明文档在 [README.fuwari.md](./README.fuwari.md)。

部署在 [Vercel](https://vercel.com) 上。
